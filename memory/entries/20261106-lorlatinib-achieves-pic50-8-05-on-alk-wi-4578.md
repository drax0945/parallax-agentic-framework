# Lorlatinib achieves pIC50 8.05 on ALK with zero rotatable bonds via 12-membered macrolactam

Lorlatinib (CHEMBL3286830), FDA approved 2018, is a 12-membered macrocyclic ALK inhibitor: measured pIC50 8.05 on ALK (biochemical), IC50 0.2 nM on EML4-ALK F1174L mutant (cellular phospho-ALK). MW 406, cLogP 2.8, TPSA 110 Å², 0 rotatable bonds. The pyrazole-pyridine aminopyrimidine core is locked into the binding conformation by an amide-ether macrocycle. CNS MPO 4.6 supports brain penetration. Compared to crizotinib (5 rotatable bonds, pIC50 ~6.6), macrocyclisation improved potency ~30-fold and removed conformational entropy cost. This validates the rotatable-bond rationale for ALK macrocycle design.
